# Figma Links

Source-of-truth mapping between this app's flows and their files in the **Homerun Product** Figma project. This is meant to stay a living index, not a one-off snapshot — update it whenever a file in Figma is renamed, split, or added.

**How to fill in a URL:** in the Figma project file list, right-click the file → **Copy link**. Paste that (not the folder URL below, which can't be traced back to an individual file).

Figma project (folder view, not a substitute for the links below): https://www.figma.com/files/1422521281944706177/folder/83214443
